# EDGE CASE LIBRARY (REAL SCHOOL SCENARIOS)

## CALENDAR EDGE CASES

- Libur mendadak (bencana / surat dinas)
- Jadwal berubah di tengah semester
- Sekolah pindah kalender akademik
- P5 / proyek berlangsung 3 minggu
- Ujian nasional + ujian sekolah overlap

---

## ATTENDANCE EDGE CASES

- murid pindah kelas di tengah bulan
- guru edit presensi lama
- murid izin retroaktif
- absensi offline sync terlambat

---

## RULE
Jika edge case tidak tercover → system FAILS TEST
